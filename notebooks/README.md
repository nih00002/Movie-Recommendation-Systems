# Notebooks

This directory contains the two recommendation-system implementations developed from the original 2022 project.

## 1. Content-Based Movie Recommender

`01_Content_Based_Movie_Recommender.ipynb`

Uses movie metadata to recommend similar movies through:

- Feature combination
- TF-IDF vectorization
- Cosine similarity
- Movie-title matching

## 2. Ratings-Based Movie Recommender

`02_Ratings_Based_Movie_Recommender.ipynb`

Uses user-rating patterns to recommend similar movies through:

- Movie-user rating matrices
- Sparse matrix representation
- k-Nearest Neighbors
- Cosine distance
- Item-based collaborative filtering

These notebooks are curated portfolio versions of recommendation-system work originally completed in **2022**.
