# Data

The original 2022 project used two movie-data sources:

- A movie metadata dataset containing fields such as title, genres, keywords, tagline, cast, and director.
- A user-ratings dataset containing movie IDs, user IDs, and numerical ratings.

The raw CSV files are intentionally not included in this portfolio repository until the exact original sources and redistribution terms are documented.
